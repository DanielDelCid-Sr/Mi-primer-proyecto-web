# Mi Primer Proyecto Web

Este proyecto corresponde a una actividad práctica de Git y GitHub.

## Descripción

Es un pequeño sitio web creado completamente de manera local utilizando Visual Studio Code.

## Tecnologías utilizadas

- HTML
- CSS
- Git
- GitHub

## Archivos del proyecto

- `index.html` - Contiene la estructura de la página web.
- `estilos.css` - Contiene los estilos visuales de la página.
- `README.md` - Contiene información sobre el proyecto.

## Objetivo

Aprender a crear un proyecto local, convertirlo en un repositorio Git y posteriormente publicarlo en GitHub utilizando comandos desde la terminal.
